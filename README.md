# Drownstar (playable test build)

A browser build of Drownstar for testing, played at https://graveofbears.github.io/Drownstar-Play/

Only the built game lives here (in `docs/`, served by GitHub Pages). The source is private.

Controls: mouse look · WASD move · Space / Ctrl rise / sink · Shift boost · F lamp · E ping (on the pulse!) ·
hold right mouse = camera, left click = photo · Tab journal · L livery · R at the dock under the station.
